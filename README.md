# Genius Bakery

## Description

A modern bakery website with a clean. This project features a responsive layout, animated sections, and a premium user experience.

## Features

- **Modern Design**: Implemented with Sass/SCSS for maintainable and modular styles.
- **Responsive Layout**: Adapts seamlessly to different screen sizes (desktop, tablet, mobile).
- **Animations**: Smooth scrolling animations and hover effects enhance user engagement.
- **Modal System**: A functional modal window for displaying detailed information.
- **Premium Feel**: High-quality assets and typography create a professional brand image.

## Getting Started

### Prerequisites

- **Node.js** and **npm** installed.
- **Gulp CLI** (for running build tasks).

### Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    cd genius-bakery
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

### Usage

Start the development server with live reload:

```bash
npm start
```

To build the project for production:

```bash
npm run build
```
